# Система учёта техники

Простое веб-приложение на Flask для учёта компьютерной и оргтехники в техникуме.

## Что умеет

- Учёт техники (инвентарный номер, кабинет, материально-ответственное лицо)
- Заявки на ремонт (обычный пользователь может подать, админ обрабатывает)
- Инвентаризация (просмотр списка)
- Списание техники (только админ)
- Две роли: администратор и обычный пользователь

## Как запустить

1. Установить зависимости:
```
pip install -r requirements.txt
```

2. Запустить:
```
python app.py
```

3. Открыть в браузере: http://127.0.0.1:5000

## Учётные записи

| Логин | Пароль | Роль          |
|-------|--------|---------------|
| admin | admin  | администратор |
| user  | user   | пользовательтель    |

База данных SQLite создаётся автоматически при первом запуске (файл `tech_uchet.db` в папке instance или рядом с app.py).
